# Dylan Video Studio

Primera versión inicial del monorepo para Dylan Video Studio.

Requerimientos:
- Node.js >= 20 (LTS)

Instalación básica:
1. Copia .env.example a .env y ajusta variables.
2. Ejecuta: npm run install:all

Estructura inicial:
- frontend/
- backend/
- remotion/
- shared/
- scripts/
- docs/
- .github/workflows/

Siguientes pasos:
- Implementar frontend, backend y remotion en iteraciones.
